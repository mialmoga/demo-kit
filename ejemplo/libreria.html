Demo Kit · librería

Música procedural que se sintetiza al cargar: sin muestras, solo código y datos.

Uso

<script src="demokit.min.js"></script>
<script>
  // dentro de un clic (los navegadores exigen un gesto para sonar)
  const song = await DemoKit.load('musica/menu.demokit.json', {
    onProgress: p => barra.style.width = p * 100 + '%'
  });
  const h = song.play({ loop: true, volume: 0.8, fadeIn: 1 });
  h.stop(1.5);   // con fundido de salida
</script>
